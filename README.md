# Jeffery Epstein x Kurup - All-in-One Telegram Bot

> The ultimate all-in-one Telegram userbot

## Features
- Spam, Raid, Group Management, Anti-PM, AFK, Notes, Filters
- Fun: dice, couples, jokes, shayari, figlet
- Utilities: shell, eval, translate, weather, QR, IP, speedtest
- Stickers: kang, sticker2png, resize
- Extra: quotes, carbon, screenshots, URL shortener, whisper

## Quick Start
```bash
git clone https://github.com/kurupdevs/JefferyEpsteinXKurup
cd JefferyEpsteinXKurup
cp .env.example .env
pip install -r requirements.txt
python main.py
```
