# 🏝️ Jeffery Epstein x Kurup - All-in-One Telegram Bot

<p align="center">
  <b>The ultimate all-in-one Telegram userbot</b><br>
  Spam + Management + Fun + Utility + Stickers + Extra
</p>

## ✨ Features

- 🎯 **Spam**: spam, fastspam, slowspam, statspam, delayspam, bigspam, raid
- 🛡️ **Management**: ban, unban, kick, mute, unmute, promote, demote, pin, unpin, purge, ro, antich, antiraid, kickdel, zombies, tagall, unbanall
- 🔒 **Security**: antipm, approve, disapprove, afk
- 📝 **Notes & Filters**: save, get, notes, delnote, fadd, filters, fdel
- 😂 **Fun**: ping, alive, couples, dice, truth, dare, joke, shayari, figlet, hug, slap, kiss, fakeinfo
- 🛠️ **Utility**: sh, eval, exec, whois, id, tr, weather, currency, qr, password, ip, google, speedtest
- 🎨 **Stickers**: kang, stp, resize
- 🔧 **Extra**: reply, copy, fwd, whisper, groupdata, members, q, webss, carbon, shorten, edit

## 📦 Quick Start

```bash
git clone https://github.com/kurupdevs/JefferyEpsteinXKurup
cd JefferyEpsteinXKurup
cp .env.example .env
pip install -r requirements.txt
python main.py
```
