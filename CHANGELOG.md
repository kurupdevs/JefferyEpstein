# Changelog

All notable changes to the JEK Userbot project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-08-06

### Added
- Initial release of JEK Userbot
- Core bot framework built on Pyrogram 2.0+
- Modular plugin system with custom module support
- AFK auto-reply module
- Alive/status check module
- Anti-PM protection module
- Fun commands: spam, stickers, random responses
- Group management: ban, unban, mute, unmute
- Notes system (save and recall)
- Ping/latency check
- Utility commands and help menu
- Docker & Docker Compose deployment support
- Heroku deployment support (Procfile, app.json)
- SQLite database backend
- Environment-based configuration

### Security
- Credentials stored via environment variables (not hardcoded)
- .env.example template provided
